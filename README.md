## 一、研究问题

1. **研究对象**：面向物联网场景中由 STM32/ESP32 等嵌入式终端构成的多设备系统，其运行状态需要被持续、可靠地采集与监控。
2. **当前问题**：传统监测方案多只关注"数据能否上报"，普遍缺乏设备身份认证与访问控制，异常/非法访问难以识别，告警链路不完整，且断网、丢包、重连等异常情况下数据可靠性与响应时延缺乏量化评估。
3. **拟解决问题**：本课题拟构建"终端—MQTT—Spring Boot 服务端—数据库—Web 端"的完整监测链路，在保障可靠上报的基础上，引入设备身份/权限控制与异常检测规则，实现设备状态监测、异常事件记录与告警，并通过实验量化消息时延、连续上报成功率与异常告警响应时间。
