# 实验设计（第一版）

> 目标：在动手做"改进"之前，先把"和谁比、测什么、改什么、怎样算有效"讲清楚。
> 本文件对应指导教师任务第 4 项。

## 0. 四个必答问题

1. **我要和谁比较？** —— 明确 Baseline / 对照组。
2. **测哪些指标？** —— 明确指标定义与测量方法。
3. **每个实验改变什么变量？** —— 明确自变量。
4. **什么结果能证明我的方法/系统有效？** —— 明确成功判据。

---

## 1. Baseline / 对照组定义

| 组别 | 说明 |
|---|---|
| **B0 基础链路** | 终端 → MQTT → Spring Boot → 数据库 → Web，仅"能上报、能显示"，无认证、无异常告警 |
| **B1 可靠链路** | 在 B0 基础上加入断网缓存、自动重连、数据补传 |
| **P 本文方法** | 在 B1 基础上加入设备身份/权限控制 + 异常规则引擎 + 告警 |

> 比较主线：**B0 / B1（Baseline） vs P（本文方法）**

---

## 2. 指标定义

| 指标 | 定义 | 单位 | 测量方法 |
|---|---|---|---|
| 消息时延 | 终端发出时刻 → Web 端可见时刻 | ms | 终端与服务器/浏览器对齐时间戳，统计均值/P95/最大值 |
| 连续上报成功率 | 成功落入数据库的消息数 / 终端发出消息数 | % | 固定时长连续上报，比对计数 |
| 异常告警响应时间 | 异常发生时刻 → 告警产生时刻 | ms | 注入异常场景并计时 |
| 漏报率 / 误报率 | 未告警的异常数 / 异常总数；误告警数 / 正常数 | % | 构造已知异常与正常样本 |
| 非法访问拦截率 | 被正确拒绝的非法请求数 / 非法请求总数 | % | 构造非法身份/越权请求 |

---

## 3. 实验清单

### 3.1 Baseline 实验（EXP-B）

- **目的**：验证基础链路可跑通，得到第一组可复现结果。
- **对比**：无（自身作为基准）。
- **变量**：节点数量（1 / 2 / 3）。
- **指标**：消息时延、连续上报成功率。
- **成功判据**：链路稳定运行，数据完整落入数据库并在 Web 端正确显示。

### 3.2 主实验（EXP-M）

- **目的**：验证本文方法（认证 + 异常告警）相对 Baseline 的有效性。
- **对比**：B1（无安全机制） vs P（本文方法）。
- **变量**：是否启用认证与异常告警机制。
- **指标**：异常告警响应时间、漏报率、误报率、非法访问拦截率、消息时延开销。
- **成功判据**：在时延开销可接受的前提下，异常告警响应更快、漏报/误报更低、非法访问可被拦截。

### 3.3 消融 / 参数实验（EXP-A）

- **目的**：说明各机制各自的贡献。
- **对比**：完整方法 vs 去掉某一模块（如去掉身份认证 / 去掉异常规则 / 去掉断网补传）。
- **变量**：逐项关闭单个机制。
- **指标**：与主实验一致。
- **成功判据**：每关闭一个机制，对应指标应明显变差，证明该机制必要。

### 3.4 异常 / 失败案例分析（EXP-F）

- **目的**：验证系统在异常与非法访问下的表现（对应最低要求第 8 条）。
- **场景（至少 1 种，建议 3 种）**：
  1. 非法设备接入（伪造 deviceId / 错误凭据）
  2. 越权访问（普通用户访问管理员接口）
  3. 设备异常（数据超阈值 / 长时间离线 / 消息格式异常）
- **变量**：异常类型。
- **指标**：是否被识别、告警响应时间、是否留下审计记录。
- **成功判据**：异常被正确识别并产生告警，非法访问被拒绝且有日志。

---

## 4. 实验变量汇总

| 实验 | 自变量 | 因变量（指标） | 对照 |
|---|---|---|---|
| EXP-B | 节点数量 | 时延、上报成功率 | 无 |
| EXP-M | 是否启用安全/告警机制 | 告警响应、漏报/误报、拦截率、时延 | B1 |
| EXP-A | 关闭哪个机制 | 同 EXP-M | 完整方法 |
| EXP-F | 异常类型 | 识别率、响应时间、审计完整性 | 正常场景 |

---

## 5. 可复现性要求

- 每个实验在 `experiments/<exp_id>/` 下记录：`config.yaml`、`command.txt`、`notes.md`、`metrics.csv`
- 固定：硬件型号、固件版本、Broker/服务端版本、网络环境、随机种子（如涉及随机）
- 每组实验重复次数：待定（建议 ≥ 3 次取统计值）
- 记录环境：见 `experiments/baseline/config.yaml`
