# 任务要求（最低完成要求 + 拓展目标）

> 来源：指导教师任务书。本文件从题目确认起冻结，作为验收依据。

## 一、最低完成要求

1. 搭建嵌入式终端（STM32 或 ESP32），完成设备状态数据采集；
2. 通过 MQTT 完成数据上报；
3. 使用 Spring Boot 搭建设备状态监测服务端，并接入数据库持久化；
4. 使用 Web 端实现实时监测与历史查询；
5. 实现设备身份认证 / 用户权限或基本访问控制；
6. 实现状态监测、异常事件记录与告警；
7. 完成基础测试：
   - 消息时延
   - 连续上报成功率
   - 异常告警响应时间
8. 至少设计一种异常 / 非法访问或设备异常场景进行验证。

## 二、拓展目标

- [ ] 多设备管理
- [ ] 日志审计
- [ ] 更丰富的异常规则或安全策略

> 拓展目标为加分项，应在最低要求全部达成后再投入精力。
