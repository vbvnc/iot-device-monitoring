# 精读阅读卡

> 至少 **5 篇**，每篇一张卡。文件名建议：`01_第一作者_年份_短标题.md`

## 阅读卡模板

```markdown
# 阅读卡：<文献标题>

- **作者 / 年份 / 出处**：
- **DOI / 链接**：
- **文献类型**（综述 / 方法 / 系统 / 评测 / 标准）：

## 1. 研究问题
（这篇文献想解决什么问题？）

## 2. 方法
（用了什么方法 / 架构 / 算法 / 系统设计？）

## 3. 数据或实验环境
（数据集、硬件、平台、参数设置？）

## 4. 评价指标
（用了哪些指标？如何测量？）

## 5. 主要结论
（作者的主要发现？）

## 6. 与我们课题的关系
（可借鉴什么？与我们的差异？能否作为 Baseline / 对照？）

## 7. 可引用点
（论文中可引用该文献支撑哪些观点？）
```
