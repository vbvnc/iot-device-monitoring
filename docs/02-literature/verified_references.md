# 已核验参考文献

> 规则：**论文最终引用的文献只能来自本文件**。每条必须真实存在、出处正式、信息完整。

## 核验标准

对每条文献逐项确认：

- [ ] 文献真实存在（能在数据库/官网检索到）
- [ ] 正式出处（期刊/会议/标准/专著，而非博客、论坛、文库）
- [ ] 作者完整
- [ ] 年份准确
- [ ] 卷期页码（如有）
- [ ] DOI / 稳定链接可访问
- [ ] 与本人课题直接相关

## 目标数量

- 核心文献：**10–15 篇**
- 精读（有阅读卡）：**≥ 5 篇**
