# 候选文献池

> 用途：存放**尚未核验**的候选文献。任何条目在核验通过前，不得写入论文参考文献。
> 核验通过后，请移动到 `verified_references.md`。

## 使用说明

1. 将指导教师给出的候选文献（或自己检索到的候选）逐条登记到下表中；
2. 每条都必须实际打开、核对真实性（真实存在、可访问）；
3. 核验通过 → 复制到 `verified_references.md` 并补全 DOI/出处；
4. 核验失败（查无此文、出处错误、无法溯源）→ 在"核验状态"标注 `假/存疑`，并**不得引用**；
5. 只登记"检索方向""关键词"而没有具体文献的条目，一律视为无效。

## 目标

- 从候选池筛出 **10–15 篇**与题目直接相关的核心文献；
- 其中**至少精读 5 篇**，形成阅读卡（放入 `reading_notes/`）。
